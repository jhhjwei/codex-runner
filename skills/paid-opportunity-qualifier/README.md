# Paid Opportunity Qualifier

A ClawHub skill that filters technical income opportunities with strict evidence gates.

## Positioning

This is not a generic bounty search tool. It is designed for developers who waste time on unclear rewards, crowded issues, unverifiable payment claims, or tasks that are too large to finish quickly.

The skill returns at most one actionable candidate and clearly labels commercial progress as `none`, `applied`, `submitted`, `accepted`, or `paid`.

## Ideal users

- developers seeking small GitHub bounties or microgrants;
- freelancers validating fixed-scope automation work;
- agent operators screening ClawHub-adjacent earning claims;
- teams that need a documented go/no-go decision before implementation.

## Free skill output

- payment evidence check;
- competition count;
- one-to-four-hour delivery estimate;
- submission path;
- risk and stop condition;
- a single next action.
